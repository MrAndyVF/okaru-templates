# Claude Code

**EN** — Writes `~/.claude/themes/okaru.json`, a custom theme built on the current light/dark mode. Claude Code
watches that folder, so palette changes apply live. Select it once with `/theme` → **OKARU**.

**ES** — Escribe `~/.claude/themes/okaru.json`, un tema propio sobre el modo claro/oscuro actual. Claude Code
vigila esa carpeta, así que los cambios de paleta se aplican al momento. Elígelo una vez con `/theme` → **OKARU**.
