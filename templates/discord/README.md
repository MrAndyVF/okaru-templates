# Discord

**EN** — One OKARU theme (`okaru.theme.css`) for every Discord client that supports themes: Vencord (native and
Flatpak), Equicord, Vesktop, Equibop, BetterDiscord, Legcord, WebCord and Dorion. It is only written for the
clients you have installed. It recolors Discord's own variables (current and older names), so it survives most
Discord updates. Enable it once in the client's *Themes* settings; Vencord-based clients reload it live.

**ES** — Un tema OKARU (`okaru.theme.css`) para todos los clientes de Discord con temas: Vencord (nativo y
Flatpak), Equicord, Vesktop, Equibop, BetterDiscord, Legcord, WebCord y Dorion. Solo se escribe en los clientes
que tengas instalados. Cambia los colores de las variables propias de Discord (nombres actuales y anteriores),
así aguanta casi todas sus actualizaciones. Actívalo una vez en *Temas* del cliente; los basados en Vencord lo
recargan al momento.
