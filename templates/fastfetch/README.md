# Fastfetch

**EN** — Recolors the named colors (`blue`, `green`, `magenta`…) used by `keyColor` and `logo.color` in
`~/.config/fastfetch/config.jsonc` with the palette (`blue` → primary, `green` → secondary, `magenta` →
tertiary…). Only those values change; each keeps its original name in a `/*okaru:green*/` comment, so disabling
the template restores the file exactly. Raw ANSI codes and everything else are left untouched.

**ES** — Cambia los colores con nombre (`blue`, `green`, `magenta`…) de `keyColor` y `logo.color` en
`~/.config/fastfetch/config.jsonc` por los de la paleta (`blue` → primario, `green` → secundario, `magenta` →
terciario…). Solo cambian esos valores; cada uno guarda su nombre original en un comentario `/*okaru:green*/`,
así que al desactivar la plantilla el archivo queda exactamente como estaba. Los códigos ANSI y el resto no se tocan.
