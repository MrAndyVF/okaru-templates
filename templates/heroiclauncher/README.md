# Heroic Games Launcher

**EN** — Writes the **okaru** theme to `~/.config/heroic/themes/okaru.css` (native and Flatpak). Once, in
*Settings → General*, set **Custom Themes Path** to that `themes` folder and pick **okaru** as the theme. Heroic
reads the file each time the theme is applied, so reopen Heroic after a palette change.

**ES** — Escribe el tema **okaru** en `~/.config/heroic/themes/okaru.css` (nativo y Flatpak). Una sola vez, en
*Ajustes → General*, pon esa carpeta `themes` en **Custom Themes Path** y elige **okaru** como tema. Heroic lee
el archivo cada vez que aplica el tema, así que vuelve a abrirlo tras cambiar la paleta.
