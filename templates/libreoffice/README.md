# LibreOffice

**EN** — Installs an **OKARU** color scheme (application UI, document, Writer/Calc marks, Basic/SQL editors,
change-tracking authors) as a LibreOffice extension. It is rebuilt and reinstalled only when the palette really
changed. Select it once in *Tools → Options → LibreOffice → Appearance → Scheme*; LibreOffice applies the new
colors after a restart. Disabling the template uninstalls the extension.

**ES** — Instala un esquema de color **OKARU** (interfaz, documento, marcas de Writer/Calc, editores de Basic/SQL,
autores del control de cambios) como extensión de LibreOffice. Se vuelve a generar e instalar solo cuando la
paleta cambió de verdad. Elígelo una vez en *Herramientas → Opciones → LibreOffice → Apariencia → Esquema*;
LibreOffice aplica los colores nuevos al reiniciarse. Al desactivar la plantilla se desinstala la extensión.
