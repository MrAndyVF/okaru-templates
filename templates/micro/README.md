# Micro

**EN** — Writes the `okaru` colorscheme to `~/.config/micro/colorschemes/` and sets `"colorscheme": "okaru"` in
`settings.json` (other settings are kept; an unreadable file is left untouched). Disabling the template removes
that line. Open files pick up the new colors on the next start of micro. Needs a truecolor terminal.

**ES** — Escribe el esquema `okaru` en `~/.config/micro/colorschemes/` y pone `"colorscheme": "okaru"` en
`settings.json` (se conserva lo demás; un archivo ilegible no se toca). Al desactivar la plantilla se quita esa
línea. micro toma los colores nuevos la próxima vez que se abre. Necesita una terminal truecolor.
