# Neovim

**EN** — Writes a regular colorscheme to `~/.config/nvim/colors/okaru.lua`: enable it with `:colorscheme okaru`
(or `vim.cmd.colorscheme("okaru")` in `init.lua`). Covers the editor UI, syntax, Tree-sitter, LSP diagnostics,
diffs, GitSigns and the built-in terminal. Running Neovim instances that use it reload on every palette change.

**ES** — Escribe un colorscheme normal en `~/.config/nvim/colors/okaru.lua`: actívalo con `:colorscheme okaru`
(o `vim.cmd.colorscheme("okaru")` en `init.lua`). Cubre la interfaz, la sintaxis, Tree-sitter, diagnósticos de
LSP, diffs, GitSigns y la terminal integrada. Los Neovim abiertos que lo usan se recargan al cambiar la paleta.
