# OBS Studio

**EN** — Writes an **OKARU** color variant of OBS's own Yami theme (native and Flatpak installs). Only colors
change, so it keeps working across OBS updates; light mode builds on Yami Light for dark icons. Select it in
*Settings → Appearance → Theme*. OBS loads theme changes on its next start.

**ES** — Escribe una variante de color **OKARU** del tema Yami de OBS (instalación nativa y Flatpak). Solo cambian
los colores, así sigue funcionando con cada versión de OBS; en modo claro parte de Yami Light para tener iconos
oscuros. Elígelo en *Ajustes → Apariencia → Tema*. OBS toma los cambios de tema al volver a abrirse.
