# Papirus folders

**EN** — Recolors the folders of the Papirus icon themes in `~/.local/share/icons` (Papirus, Papirus-Dark,
Papirus-Light, ePapirus…) with the Papirus folder color closest to the palette's primary color, using
`papirus-folders`. It never asks for root: system-wide themes in `/usr/share/icons` are left alone (copy the theme
to your user folder to recolor it). It only runs when the chosen color changes. Disabling the template restores
the default folder color. When your icon theme is a Papirus variant, it also switches between Papirus-Dark
and Papirus-Light with the light/dark mode.

**ES** — Recolorea las carpetas de los temas de iconos Papirus de `~/.local/share/icons` (Papirus, Papirus-Dark,
Papirus-Light, ePapirus…) con el color de carpeta de Papirus más cercano al primario de la paleta, usando
`papirus-folders`. Nunca pide root: los temas del sistema en `/usr/share/icons` no se tocan (copia el tema a tu
carpeta de usuario para recolorearlo). Solo trabaja cuando cambia el color elegido. Al desactivar la plantilla las
carpetas vuelven al color de fábrica. Si tu tema de iconos es un Papirus, además cambia entre Papirus-Dark y
Papirus-Light según el modo claro/oscuro.
