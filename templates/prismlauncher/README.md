# Prism Launcher

**EN** — Writes the **OKARU** theme to Prism Launcher's `themes/OKARU/` (native and Flatpak): Qt palette on
Fusion plus colors for the game log. Select it in *Settings → Launcher → User Interface → Theme*; Prism applies
palette changes the next time it starts.

**ES** — Escribe el tema **OKARU** en `themes/OKARU/` de Prism Launcher (nativo y Flatpak): paleta Qt sobre
Fusion y colores para el registro del juego. Elígelo en *Ajustes → Launcher → Interfaz → Tema*; Prism toma los
cambios de paleta la próxima vez que se abre.
