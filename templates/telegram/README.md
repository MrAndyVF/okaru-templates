# Telegram

**EN** — Writes `~/.config/telegram-desktop/themes/okaru.tdesktop-palette` from the palette (window, chat list,
bubbles, panels, menus). Telegram derives every other color from these. Load it once in *Settings → Chat
Settings → ⋮ → Create new theme / Choose from file*; to refresh after a palette change, load it again.

**ES** — Escribe `~/.config/telegram-desktop/themes/okaru.tdesktop-palette` desde la paleta (ventana, lista de
chats, burbujas, paneles, menús). Telegram deriva el resto de colores de estos. Cárgalo una vez en *Ajustes →
Ajustes de chats → ⋮ → Elegir desde archivo*; para refrescarlo tras cambiar la paleta, vuelve a cargarlo.
