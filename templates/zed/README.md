# Zed

**EN** — Writes one theme family with **OKARU Dark** and **OKARU Light** to `~/.config/zed/themes/okaru.json`
(and to Gram when it is installed). Zed reloads it live. To follow the system light/dark mode:

**ES** — Escribe una familia con **OKARU Dark** y **OKARU Light** en `~/.config/zed/themes/okaru.json` (y en
Gram si está instalado). Zed la recarga al momento. Para seguir el modo claro/oscuro del sistema:

```json
"theme": { "mode": "system", "light": "OKARU Light", "dark": "OKARU Dark" }
```
